# PersonaWeaver 复赛提交文档索引

本目录用于存放准备提交到 GitHub 仓库的公开文档。原 `docs/` 目录作为本地讨论、历史材料、共识记录和草稿空间，不进入新仓库提交范围。

## 文档边界

- `docs/submit/`：公开提交文档，允许进入 GitHub 仓库。
- `docs/local/`：本地自用文档，仅保留占位文件，不提交具体内容。
- `docs/共识/`：团队与 SOLO 讨论后确认的共识，作为本地决策记录，不直接提交到公开仓库。

## 当前已确认可共同完善的文档

1. 复赛项目说明文档：说明 PersonaWeaver 的定位、功能边界、运行方式和提交材料结构。
2. 后端运行说明：说明后端启动方式、环境变量、Supabase、OSS 和 vivo AIGC API 配置方式。
3. 数据库说明：说明 Supabase 表结构、RAG 向量表设计和初始化 SQL。
4. API 对接说明：说明后端对前端保留的接口、请求参数、返回结构和兼容边界。
5. source_preprocess 模块说明：说明输入源适配、文本标准化、清洗、章节切分的模块职责。
6. RAG 轻量演示说明：说明按 user_id 权限隔离、按 book_id 检索隔离、top-k 检索和 token 成本优化边界。
7. vivo AIGC API 接入说明：说明 provider 接入方式、环境变量和调用场景。

## 不进入公开提交的内容

1. 本地 `.env`、数据库密码、API Key、OSS 密钥。
2. 历史校内赛草稿、旧 topic 项目介绍、临时测试记录。
3. 未确认的讨论草案和个人笔记。
4. 大体积原始数据、论文材料、视频、图片缓存和测试输出。
