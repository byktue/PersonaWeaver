========================================================
 PersonaWeaver 启动说明
========================================================

需要先启动【后端】，再启动【前端】。

--------------------------------------------------------
一、启动后端
--------------------------------------------------------
1. 进入文件夹：backend\dist\personaweaver-backend\
2. 首次使用：把 .env.example 复制一份改名为 .env，
   用记事本打开填入 API Key（至少填 vivo 一组）。
3. 双击运行：启动后端.bat
4. 看到 “Uvicorn running on http://127.0.0.1:8000” 即成功。
   保持这个黑窗口开着（关掉=停止后端）。

--------------------------------------------------------
二、启动前端
--------------------------------------------------------
1. 确认后端已在运行。
2. 进入文件夹：frontend\release\win-unpacked\
3. 双击运行：PersonaWeaver.exe
4. 弹出登录窗口即成功，登录后即可使用。

--------------------------------------------------------
常见问题
--------------------------------------------------------
· 后端双击闪退：多是没创建 .env，或端口 8000 被占用。
· 前端白屏/登录失败：后端没启动，或 .env 配置不对。
· 前端别单独把 exe 拷出来运行，要整个 win-unpacked 文件夹。
· 两个文件夹建议放非系统盘（D/E 盘），不占用 C 盘。

详细自测步骤见：docs_local\共识\人工自测验证共识.md
